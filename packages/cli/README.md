# @repo-knowledge/cli

Phase 0 placeholder for the `board` CLI.

This package owns the `board` binary and registers the MVP command names:

- `init`
- `start`
- `status`
- `doctor`
- `explain`
- `task`
- `verify`
- `stop`

The commands intentionally return placeholder output in Phase 0. Repository discovery, contract loading, bootstrap behavior, MCP startup, and verification behavior belong to later phases.
