# Agent Tools

Phase 0 placeholder for Board's policy-checked agent tool boundary.

## Future Ownership

This package will eventually own:

- Tool schemas
- Tool-call records
- Policy checks before tool execution
- Tool result shapes for LangGraph workflows
- Tool adapters for repository scanning, contract validation, diffs, retrieval, approvals, and GitHub operations

## Non-Goals

This package does not decide which agent should run, which model to call, or whether a human approval should be granted.
