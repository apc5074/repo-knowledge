# Agent Memory

Phase 0 placeholder for Board's agent memory and retrieval metadata package.

## Future Ownership

This package will eventually own:

- Agent memory record shapes
- Repository fact memory
- Known-problem memory
- Artifact proposal history
- Approval decision history
- Embedding and retrieval metadata boundaries

## Non-Goals

This package must not store secret values, raw local logs by default, private shell history, or unrestricted source snapshots.
