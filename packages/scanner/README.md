# @repo-knowledge/scanner

Phase 0 placeholder for deterministic repository analysis.

This package will own scanner core behavior in Phase 3. It should stay deterministic and callable as an auditable tool by future Board maintenance agents.

Planned Phase 3 detector domains:

- languages.
- package managers.
- frameworks.
- applications and services.
- entry points.
- build, start, test, lint, typecheck, migration, seed, and health-check commands.
- Dockerfiles.
- Docker Compose services.
- Dev Container configuration.
- GitHub Actions workflows.
- required environment variable names.
- PostgreSQL, Redis, and common local dependencies.
- migration and seed directories.
- API routes.
- background workers.
- generated files.
- existing documentation and agent instruction files.

No real repository detectors run in Phase 0.
