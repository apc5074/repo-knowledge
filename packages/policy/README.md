# Policy

Phase 0 placeholder for Board's agent safety and policy package.

## Future Ownership

This package will eventually own:

- Policy definitions
- Policy decision records
- Safety classifications
- Boundaries for filesystem, shell, network, secret, model-call, GitHub write, and artifact approval actions

## Non-Goals

This package does not implement tools, run agent workflows, or call model providers. It decides whether requested actions are allowed, blocked, or require approval.
