# Web

Phase 0 placeholder for Board's hosted product UI.

## Future Ownership

This app will eventually own the hosted UI for:

- Repository readiness status
- Agent run history
- Artifact proposals
- Human approval queues
- Known problems
- Organization and repository settings

## Phase 0 Boundary

The web app currently exports package identity and a static placeholder shell.

It must not require a running API, authentication, database, hosted agent worker, or production frontend framework behavior in Phase 0.
